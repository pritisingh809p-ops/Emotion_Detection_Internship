# Vehicle Drowsiness Detection Model

## Features
1. **Multi-Person Cabin Detection:** Detects multiple passengers/drivers in vehicle images or video streams.
2. **Drowsiness & Sleep Analysis:** Identifies who is sleeping vs awake.
3. **Red Highlighting & Age Estimation:** Marks sleeping occupants in red and estimates their age.
4. **Pop-Up Alert Messages:** Displays prominent warning pop-up notifications containing sleeping counts and ages.

## Installation & Running
```bash
pip install -r requirements.txt
streamlit run app.py
```
