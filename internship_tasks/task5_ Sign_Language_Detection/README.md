# Sign Language Detection System

## Features
1. **Operational Time Window:** Active daily from 6:00 PM to 10:00 PM.
2. **Dual Input Modes:** Image upload and real-time webcam streaming.
3. **Sign Recognition:** Predicts known words (HELLO, THANK_YOU, YES, NO, PLEASE, HELP, GOODBYE).

## Installation & Running
```bash
pip install -r requirements.txt
streamlit run app.py
```
