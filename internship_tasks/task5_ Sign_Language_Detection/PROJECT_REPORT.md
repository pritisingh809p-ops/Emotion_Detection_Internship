**Submitted by:** Priti Vijay Singh  
**Program:** B.E. Computer Science Engineering – Data Science  

## 1. Abstract
This report presents the implementation of the Sign Language Detection System, featuring both image upload and real-time video/webcam support, strict time-window operational validation (active 6 PM to 10 PM), and recognition of known words (`HELLO`, `THANK_YOU`, `YES`, `NO`, `PLEASE`, `HELP`, `GOODBYE`).

## 2. System Features
- **Time Window Enforcement:** Active only between 18:00 and 22:00.
- **Dual GUI Modes:** Image upload preview and real-time webcam frame processing.
- **Known Word Recognition:** Accurate detection of core sign gestures.
