# Dataset Information

## Dataset Name

RAF-DB Facial Expression Dataset

## Purpose

The dataset was used to train the CNN-based facial emotion
classification model.

## Emotion Classes

1. Surprise
2. Fear
3. Disgust
4. Happy
5. Sad
6. Angry
7. Neutral

## Preprocessing

The image preprocessing pipeline includes:

- Face detection
- Face cropping
- Image resizing to 100 × 100
- Pixel normalization
- Tensor preparation

## Dataset Storage

The dataset is stored separately in Google Drive because of
dataset size and distribution considerations.

The dataset is not directly included in this GitHub repository.
